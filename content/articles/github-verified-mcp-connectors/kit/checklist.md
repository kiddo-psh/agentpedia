# 점검 체크리스트

## 목록
- [ ] 레포 안 MCP 설정(`.mcp.json`, `.cursor/mcp.json`, `.claude/`, `.codex/` 등)의 서버를 모두 적었다.
- [ ] 홈 디렉터리 MCP 항목은 읽기만 했고, 이름·명령·URL만 적었다.
- [ ] 키·토큰 값은 출력·저장하지 않았다.

## 분류
- [ ] 각 서버에 검증된 커넥터 대체 검토 / 사설 유지 / 허용 목록 후보(또는 판단 보류)를 붙였다.
- [ ] 커넥터 대체 여부는 현재 공식 문서·Changelog 기준으로만 적었고, 추측한 서비스는 판단 보류로 뒀다.
- [ ] 플러그인·훅·확장 침해 점검(agent-tools-trust-boundary)으로 범위를 넓히지 않았다.

## 변경
- [ ] 홈 디렉터리 파일은 수정하지 않았다.
- [ ] 엔터프라이즈 managed-settings는 수정하지 않았고, URL 초안만 보고서에 적었다.
- [ ] 레포 설정은 승인한 항목만 바꿨고, 바꾼 파일이 파서를 통과했다.
- [ ] `docs/mcp-connector-inventory.md`에 비밀 값 패턴이 없음을 grep으로 확인했다.
