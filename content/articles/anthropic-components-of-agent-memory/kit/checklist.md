# 점검 체크리스트

## 측정
- [ ] 자동 메모리 디렉터리와 레포 지시 파일이 모두 없으면 아무것도 바꾸지 않고 멈췄다.
- [ ] 자동 메모리 경로를 추측하지 않고 사용자 확인(또는 꺼짐 판정)을 받았다.
- [ ] 측정 전에 메모리 파일의 크기와 수정 시각(또는 sha256)을 기록했다.
- [ ] `MEMORY.md`의 줄 수와 바이트를 실제 명령으로 셌다.
- [ ] 200줄과 25KB(25,000·25,600바이트) 중 먼저 닿는 한도와 한도 밖 줄 범위를 적었다.
- [ ] 보고서에 25KB 정의 한계와 "한도 밖 줄은 로드되지 않는다"를 적었다.
- [ ] 지시 파일별 줄 수를 세고 200줄 이상인 파일을 표시했다.
- [ ] AGENTS.md 로드 여부를 단순 규칙(또는 사용자 확인)으로만 표시했고, 버전·플러그인 장문을 쓰지 않았다.
- [ ] 주제별 파일 개수와 크기를 적었다.

## 분류
- [ ] 항목마다 유지·낡음·중복·이동 후보 중 하나로 분류하고 근거를 한 줄 적었다.
- [ ] 선별(selective)·덤프(dump)·드리밍·위키 후보를 표시했다(해당 항목이 있으면).
- [ ] "낡음"은 레포를 열어 확인한 뒤에 했다.
- [ ] 사람 지시 vs 배운 내용의 위치가 맞는지 확인했다.
- [ ] 틀린 경로·명령이 있으면 따로 표시했다.
- [ ] 드리밍·위키를 실제로 돌리거나 만들지 않았다.

## 변경
- [ ] 측정 전후 크기·수정 시각을 비교해 홈 메모리 파일이 그대로임을 확인했고, 설정은 수정하지 않았다.
- [ ] 미커밋 변경이 있는 지시 파일은 따로 승인받은 경우에만 고쳤다.
- [ ] 계획을 보여주고 승인한 뒤에만 보고서를 만들었고, 승인 없이 덮어쓰지 않았다.
- [ ] 레포 `CLAUDE.md`(또는 `AGENTS.md`)는 승인한 줄만 바꿨고, `.claude/CLAUDE.md`와 `CLAUDE.local.md`는 수정하지 않았다.
- [ ] 지시 파일을 줄였다면 수정 후 줄 수가 200줄 미만임을 보고했다.
- [ ] 지시 파일을 고친 뒤 `git diff`를 보여 줬다.
- [ ] 작업 후 `git status --short`가 승인한 파일과 보고서만 달라졌다. 커밋·푸시는 하지 않았다.
- [ ] 비밀 값은 파일·줄 번호만 적었고, 보고서에서 대표 패턴 grep 결과가 없다(단정하지 않음).
- [ ] 보고서에 메모리 원문을 옮기지 않았다.
