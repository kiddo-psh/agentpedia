2026년 3월 공개된 Mixergy 인터뷰에서 Postiz 창업자 Nevo David는 매출 이야기를 꺼냈습니다. Postiz는 SNS 예약 글을 올려 주는 오픈소스 도구입니다. 그는 "에이전트 쪽으로 보내기 시작하자 매출이 폭발했다"는 취지로 말했습니다. 사람이 화면에서 쓰던 도구를 에이전트도 직접 쓸 수 있게 열었다는 이야기입니다.

그 뒤 몇 달 사이 Postiz의 매출은 어떻게 움직였을까요?

반대편에는 SEO 글 자동 작성 서비스 SEObot이 있습니다. 사례 모음 사이트 Horizontal은 2026년 11월 5일 두 서비스를 같은 분류에 넣어 소개했습니다. 이 글은 둘을 나눠 봅니다. 한쪽은 에이전트가 쓰는 도구를 열었고, 다른 쪽은 에이전트가 만든 글을 팝니다.

## 에이전트 접점을 연다는 것은 무슨 뜻인가

SaaS는 보통 사람이 화면에서 쓰도록 만듭니다. 기능이 있어도 버튼은 브라우저 안에 있습니다. 코딩 에이전트에게 "내일 오전 9시에 글을 예약해 줘"라고 시키면, 에이전트는 화면을 눌러 보거나 API 문서를 읽고 호출을 직접 짜야 합니다. 이 글은 <Term id="cli">CLI</Term>, <Term id="agent-skill">스킬</Term>, <Term id="mcp">MCP</Term>처럼 에이전트가 직접 다루는 입구를 "에이전트 접점"이라고 부릅니다.

Horizontal은 Nevo가 2025년 말 기준 혼자 개발하고 있었다고 본인이 말했다고 옮깁니다. 2026년 7월에도 1인 운영으로 소개된 적이 있다고 덧붙입니다. 인터뷰에서 Nevo는 모두가 MCP를 이야기하던 때에 먼저 MCP를 붙였다고 말했습니다. 그가 전환점으로 꼽은 것은 에이전트 OpenClaw의 등장입니다.

그는 Claude에게 공개 API를 CLI로 바꾸게 해 npm에 올렸다고 말했습니다. 이 CLI를 쓰는 스킬도 ClawHub에 올려 설치할 수 있게 했다고 합니다. Horizontal도 Nevo가 Claude Code로 공개 API를 CLI로 만들었다고 전합니다. 정확한 시점은 공개 대본에 없습니다.

이 접점이 실제로 쓰였다는 단서도 있습니다. 한 크리에이터가 자기 OpenClaw 에이전트 Larry에게 TikTok 게시를 맡긴 과정을 글로 썼습니다. Horizontal은 Larry가 Postiz로 TikTok 슬라이드쇼를 올렸고, 이 글로 체험 가입이 약 700건 나왔다고 Nevo가 말했다고 전합니다. 이 수치는 따로 검증되지 않았습니다. 그 글이 언제 올라왔는지도 공개 출처에 없습니다.

Postiz GitHub README(2026년 11월 12일 열람)는 MCP, CLI와 Claude, ChatGPT, Codex, OpenClaw, Cursor 연동을 클라우드와 셀프호스팅 모두에 갖췄다고 적습니다. 2026년 4월 16일 Nevo의 블로그 글은 CLI를 `npm install -g postiz`로 설치한다고 안내합니다. 브라우저 자동화 없이 예약하도록 CLI, REST API, MCP 서버를 함께 제공한다고도 씁니다.

확인된 시점은 세 가지입니다. 2026년 2월 매출이 전달의 약 2.5배로 뛰었습니다(TrustMRR). 3월 11일 공개된 인터뷰에서 CLI와 스킬이 언급됐습니다. 4월 16일 블로그 글이 CLI 설치를 안내했습니다. CLI와 스킬을 언제 냈는지는 공개 자료에 없어, 2월 급증과의 선후는 알 수 없습니다.

<KeyIdea title="에이전트 접점을 여는 것이 새 성장 경로일 수 있습니다">
Postiz가 한 일은 새 기능이 아니라, 이미 있던 기능에 CLI, 스킬, MCP라는 입구를 낸 것입니다. Nevo는 2026년 3월 공개된 인터뷰에서 CLI로 바꾸면 모든 것이 훨씬 짧아진다고 말했습니다. 에이전트가 모델에 보내는 토큰을 크게 줄이는 것이 목표라고도 했습니다.
</KeyIdea>

인터뷰 공개 대본에서 그는 짧은 스킬 파일과 긴 요청을 비교할 뿐, MCP와 직접 비교하지는 않습니다. Horizontal은 그가 스킬이 MCP보다 컨텍스트를 덜 쓴다고 말했다고 옮깁니다.

## 매출은 얼마나 올랐는가

<Term id="trustmrr">TrustMRR</Term>는 Stripe API 키나 OAuth 같은 소유자 승인 자격 증명으로 결제 기록을 가져와 매출을 계산한다고 밝힙니다. 이 글에서 "매출"은 TrustMRR의 월 매출 합계를 뜻합니다. 아래 값은 2026년 11월 11일 동기화 기준입니다.

| 월 | 매출 |
|---|---|
| 2025년 12월 | $15,785 |
| 2026년 1월 | $18,300 |
| 2026년 3월 | $82,076 |
| 2026년 6월 | $152,041 |
| 2026년 10월 | $387,146 |

1월에서 10월까지 약 21배입니다. 비율로 가장 크게 뛴 달은 2월로, 1월 $18,300이 한 달 만에 $46,019가 됐습니다. 그 사이 무엇이 바뀌었는지는 공개된 출처에 없습니다. Mixergy 인터뷰가 공개된 3월은 한 달 매출이 $82,076으로 마감된 달이고, 10월 $387,146은 인터뷰 뒤의 일입니다.

11월은 부분 집계($176,776)라 비교하지 않고, 같은 동기화의 <Term id="mrr">MRR</Term>(월 반복 매출)은 $403,954입니다. Horizontal은 10월을 $387,214로 적었지만 이 글은 TrustMRR 원본 값을 씁니다. Horizontal은 이 사례를 한 줄로 요약합니다.

Made his open-source post scheduler agent-first; revenue up 21x
</Quote>

Nevo는 인터뷰에서 사업 초기도 돌아봤습니다. 9월에 $350에서 시작해 조금씩 자랐고, 몇 달 정체한 뒤 약 $17K~$20K MRR에 이르렀다고 합니다(연도는 공개 대본에 없습니다). 인터뷰 당시에는 월 $45,000에 이르렀다고 말했습니다. TrustMRR의 매출과는 기준이 달라 나란히 놓지 않습니다.

## 반대편에서는 무슨 일이 있었나

John Rush는 2023년 9월 SEObot을 내고 글 자동 작성을 파는 창업자입니다. Horizontal은 그의 X 팔로워 11만 6천 명이 SEObot의 출발을 도왔다고 씁니다. Horizontal의 설명으로는, 사이트를 연결하면 SEObot이 리서치부터 글 작성, CMS 게시, 내부 링크 갱신까지 자동으로 합니다. Horizontal은 SEObot 사이트가 200,000편 이상을 썼다고 내세운다고 전합니다(시점은 밝히지 않았습니다).

TrustMRR의 2026년 11월 11일 갱신 값으로 MRR은 $32,315, 활성 구독은 477개입니다.

같은 Horizontal 글은 TrustMRR의 월 매출을 인용해, SEObot이 2026년 1월 $103,105에서 10월 $34,680으로 약 3분의 2 줄었다고 씁니다. 이 월별 값은 TrustMRR 원본에서 읽지 못한 2차 서술입니다.

하락의 이유는 공개되지 않았다고 Horizontal은 씁니다. 같은 글은 시장의 변화를 이렇게 짚습니다.

## 그래서 접점을 여는 쪽이 이기는가

이 자료로는 그렇다고 말할 수 없습니다. SNS 예약 도구와 SEO 글 자동 작성은 고객도 가격도 경쟁자도 달라, 두 서비스를 비교해 원인을 가릴 수 없습니다. SEObot의 하락 이유는 공개되지 않았습니다. Postiz의 성장 원인은 Nevo의 진술에 기댑니다. 후보는 MCP를 붙인 일, OpenClaw의 등장, 한 크리에이터의 글입니다. 각각의 기여는 공개 자료로 가를 수 없습니다.
