2026년 3월, Postiz 창업자 Nevo David는 Mixergy 인터뷰에 나왔습니다. Postiz는 SNS 예약 글을 올려 주는 오픈소스 도구입니다. 그가 꺼낸 이야기는 기능이 아니라 고객이었습니다. 에이전트를 상대로 하기 시작한 뒤 매출이 크게 올랐다는 것입니다. 인터뷰 제목도 "Revenue jumped when he sold to AI agents"입니다. 그가 예로 드는 에이전트는 OpenClaw입니다.

<Term id="trustmrr">TrustMRR</Term>는 이 수치를 Postiz의 Stripe 계정에 API 키로 연결해 결제 기록에서 계산한다고 밝힙니다. 그 월 매출은 2026년 1월 $18,300에서 10월 $387,146으로 약 21배가 됐습니다(2026년 11월 11일 동기화 기준).

반대편에는 SEO 글 자동 작성 서비스 SEObot이 있습니다. 사례 모음 사이트 Horizontal(2026년 11월 5일 게시)은 이 서비스의 월 매출이 1월 $103,105에서 10월 $34,680으로 줄었다고 전합니다. Horizontal은 두 서비스를 같은 분류에 넣었습니다. 하지만 이 글은 둘을 이렇게 나눠 봅니다. 한쪽은 에이전트가 쓰는 접점을 열었고, 다른 쪽은 에이전트가 쓴 결과물을 팔았습니다.

Nevo의 말이 맞다면 답은 간단해 보입니다. 하지만 두 수치 사이에는 확인되지 않은 빈칸이 있습니다.

## 에이전트가 직접 쓰는 접점을 연다는 것은 무슨 뜻인가

SaaS는 보통 사람이 화면에서 쓰도록 만듭니다. 기능이 있어도 버튼은 브라우저 안에 있습니다. 코딩 에이전트에게 "내일 오전 9시에 글을 예약해 줘"라고 시키면, 에이전트는 화면을 눌러 보거나 API 문서를 읽고 호출을 직접 짜야 합니다. 이 글은 <Term id="cli">CLI</Term>, <Term id="agent-skill">스킬</Term>, <Term id="mcp">MCP</Term>처럼 에이전트가 직접 다루는 입구를 "접점"이라고 부릅니다.

Mixergy 인터뷰(2026년 3월 11일) 페이지에 공개된 대본 일부에서 Nevo는 먼저 MCP를 붙였다고 말합니다. 이후 OpenClaw가 뜨자 CLI와 스킬을 냈다고 합니다. 그는 Claude에게 공개 API를 CLI로 바꾸게 해 npm에 올렸고, 그 CLI를 쓰는 짧은 스킬을 ClawHub에 올렸다고 말합니다. 전체 인터뷰는 유료이고 공개 대본에 타임스탬프가 없어, 이 글은 그의 말을 요약해 옮깁니다. Horizontal은 Nevo가 Claude Code로 공개 API를 CLI로 만들었다고 전합니다.

한 크리에이터가 자기 에이전트로 TikTok 슬라이드쇼를 올렸고 체험 가입 약 700건이 나왔다고 Horizontal은 전합니다. 본인 진술을 옮긴 2차 출처입니다.

2026년 11월 12일에 연 Postiz GitHub README는 MCP, CLI와 Claude, ChatGPT, Codex, OpenClaw, Cursor 커넥터를 클라우드와 셀프호스팅 모두에 갖췄다고 적습니다. 2026년 4월 16일 Nevo의 블로그 글(본인의 홍보글)은 CLI를 `npm install -g postiz`로 설치한다고 안내하고, 브라우저 자동화 없이 예약하도록 CLI, REST API, MCP 서버를 함께 제공한다고 씁니다. README에서 skill이라는 말은 찾지 못했습니다. 공개 출처로는 CLI와 스킬을 낸 날짜와 매출이 뛴 시점의 선후를 가릴 수 없습니다.

<KeyIdea title="에이전트가 직접 쓸 수 있는 접점을 여는 것이 새 성장 경로일 수 있습니다">
Postiz가 한 일은 새 기능을 추가한 것이 아닙니다. 이미 있던 기능에 CLI, 스킬, MCP라는 접점을 낸 것입니다. Nevo는 Mixergy 인터뷰에서 짧은 CLI 명령과 스킬 파일이 긴 API 요청보다 컨텍스트와 토큰을 덜 쓰고, 에이전트가 반복하기 쉽다고 말합니다. Horizontal은 그가 MCP보다도 컨텍스트를 덜 쓴다고 말했다고 전합니다.
</KeyIdea>

## 매출은 얼마나 올랐는가

TrustMRR가 Stripe 연동으로 검증한 Postiz의 월 매출입니다(2026년 11월 11일 동기화 기준, 2025년 12월~2026년 10월).

표에서 비율로 가장 크게 뛴 달은 2월입니다. 1월 $18,300이 한 달 만에 $46,019가 됐습니다. 그 사이 무엇이 바뀌었는지는 공개된 출처에 없습니다. Nevo가 인터뷰한 3월 11일은 매출이 이미 $82,076으로 오르던 때였고, 10월 $387,146은 인터뷰 뒤의 일입니다.

2026년 11월은 부분 집계($176,776)라 비교하지 않습니다. 같은 날 동기화 기준 <Term id="mrr">MRR</Term>은 $403,954입니다. 위 표는 월 매출, 이 값은 월 반복 매출이라 서로 다른 지표입니다. Horizontal은 이 사례를 한 줄로 요약합니다.

Nevo는 인터뷰에서 사업 초기를 이렇게 돌아봅니다. 9월에 월 $350 수준에서 시작해 조금씩 자랐고, 몇 달 정체한 뒤 약 $17K~$20K MRR까지 올랐다고 합니다. 같은 페이지의 소개문은 $45K 이상 MRR이라고 서술하고, 대본 끝에서 Nevo도 월 $45,000에 도달했다고 말합니다(TrustMRR의 월 매출과는 지표와 시점이 달라 직접 비교하지 않습니다).

## 반대편에서는 무슨 일이 있었나

SEObot은 존 러시(John Rush)가 2023년 9월에 낸 서비스입니다. 그는 이 서비스의 창업자입니다(출처에서 확인되는 것은 여기까지입니다). Horizontal의 설명으로는, 사이트를 연결하면 리서치부터 글 작성, CMS 게시, 내부 링크 갱신까지 자동으로 합니다. Horizontal은 SEObot 사이트가 200,000편 이상을 썼다고 주장한다고 전합니다.

TrustMRR의 2026년 11월 11일 갱신 값으로 MRR은 $32,315, 활성 구독은 477개입니다.

2026년 11월 5일 게시된 Horizontal은 TrustMRR의 월 매출을 인용해 SEObot이 1월 $103,105에서 10월 $34,680으로 약 3분의 2 줄었다고 씁니다. 이 월별 수치는 TrustMRR에서 직접 확인하지 못한 2차 서술입니다. 2월부터 10월까지 매달 내렸다는 주장도 같은 이유로 옮기지 않습니다.

하락의 이유는 공개되지 않았다고 Horizontal은 씁니다. 같은 글은 시장의 변화를 이렇게 짚습니다.

## 그래서 접점을 여는 쪽이 이기는가

이 자료로는 그렇다고 말할 수 없습니다. 이유는 네 가지입니다.

**시장이 다릅니다.** SNS 예약 도구와 SEO 글 자동 작성은 고객도 가격도 경쟁자도 다릅니다. 같은 해의 두 수치를 나란히 놓았을 뿐, 하나가 다른 하나의 원인이 아닙니다.

**Postiz의 성장 원인은 Nevo의 진술입니다.** MCP를 붙인 시기, OpenClaw 사용자의 관심, 한 크리에이터의 바이럴 글이 매출에 각각 얼마나 보탰는지는 공개된 자료로 가를 수 없습니다.

**SEObot의 하락 이유는 공개되지 않았습니다.** 비슷한 도구가 늘었다는 Horizontal의 관찰이 있을 뿐, 그것이 원인인지는 확인되지 않습니다.

**사례 대부분이 자기 보고입니다.** Postiz 블로그의 월 $98K 사용자 사례(2026년 4월 16일)도 Nevo 본인의 홍보글이라 근거로 쓰지 않았습니다.

3월의 인터뷰에서 Nevo는 손님이 바뀌었다고 말했습니다. 그 말이 매출의 원인인지는 이 자료로 알 수 없습니다. 다만 2026년 11월 기준으로 Postiz의 월 반복 매출은 $403,954이고, 질문은 남습니다. 내 서비스를 코딩 에이전트가 브라우저 없이 쓸 수 있는가? 쓸 수 있다면 어떤 접점으로 열려 있는가? 아래 진단 프롬프트로 먼저 확인해 보세요.
