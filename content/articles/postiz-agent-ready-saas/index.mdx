2026년 3월 공개된 Mixergy 인터뷰에서 Postiz 창업자 Nevo David는 매출 이야기를 꺼냈습니다. Postiz는 SNS 예약 게시를 해 주는 오픈소스 도구입니다. 그는 "에이전트 쪽으로 보내기 시작하자 매출이 폭발했다"는 취지로 말했습니다. 사람이 화면에서 쓰던 도구를 에이전트도 직접 쓸 수 있게 바꿨다는 뜻입니다.

비교할 서비스로 SEO 글을 자동으로 써 주는 SEObot이 있습니다. 사례 모음 사이트 Horizontal은 2026년 11월 5일 두 서비스를 같은 분류로 묶어 소개했습니다. 하지만 둘이 하는 일은 다릅니다. Postiz는 에이전트가 쓰는 도구를 만들고, SEObot은 에이전트가 쓴 글을 팝니다. 이 글은 두 서비스를 나눠서 봅니다.

SaaS는 보통 사람이 화면에서 쓰도록 만듭니다. 기능이 있어도 버튼은 브라우저 안에 있습니다. 코딩 에이전트에게 "내일 오전 9시에 글을 예약해 줘"라고 시켜 봅시다. 에이전트는 화면을 직접 누르거나, API 문서를 읽고 호출 코드를 짜야 합니다. 이 글에서는 <Term id="cli">CLI</Term>, <Term id="agent-skill">스킬</Term>, <Term id="mcp">MCP</Term>처럼 에이전트가 바로 쓸 수 있는 입구를 "에이전트 접점"이라고 부릅니다.

Postiz는 이 접점을 일찍 갖췄습니다. Horizontal에 따르면 Nevo는 2025년 말까지 혼자 개발했다고 말했습니다. 2026년 7월에도 1인 운영으로 소개된 적이 있다고 합니다. 인터뷰에서 Nevo는 모두가 MCP 이야기를 할 때 먼저 MCP를 붙였다고 말했습니다. 그가 전환점으로 꼽은 사건은 에이전트 OpenClaw의 등장입니다.

그는 Claude에게 공개 API를 CLI로 바꾸게 한 뒤 npm에 올렸다고 말했습니다. 이 CLI를 쓰는 스킬도 ClawHub에 올려 누구나 설치할 수 있게 했습니다. Horizontal도 Nevo가 Claude Code로 공개 API를 CLI로 만들었다고 전합니다. 정확한 시점은 공개 대본에 없습니다.

실제로 쓰인 흔적도 있습니다. 한 크리에이터가 자기 OpenClaw 에이전트 Larry에게 TikTok 게시를 맡긴 과정을 글로 썼습니다. Horizontal에 따르면, Larry는 Postiz로 TikTok 슬라이드쇼를 올렸습니다. Nevo는 이 글 덕분에 체험 가입이 약 700건 들어왔다고 말했습니다. 이 수치는 따로 검증되지 않았고, 글이 올라온 날짜도 공개 출처에 없습니다.

지금 Postiz는 여러 입구를 갖추고 있습니다. GitHub README(2026년 11월 12일 열람)에 따르면 MCP와 CLI가 있습니다. Claude, ChatGPT, Codex, OpenClaw, Cursor 연동도 클라우드와 셀프호스팅 양쪽에서 됩니다. 2026년 4월 16일 Nevo가 쓴 블로그 글은 `npm install -g postiz`로 CLI를 설치하라고 안내합니다. 브라우저 자동화 없이 예약할 수 있도록 CLI, REST API, MCP 서버를 함께 준다고도 씁니다.

날짜가 확인되는 일은 세 가지입니다. 2026년 2월 매출이 전달의 약 2.5배로 뛰었습니다(TrustMRR). 3월 11일 공개된 인터뷰에서 CLI와 스킬 이야기가 나왔습니다. 4월 16일 블로그 글이 CLI 설치 방법을 안내했습니다. CLI와 스킬을 낸 날짜는 공개 자료에 없습니다. 그래서 2월 급증보다 먼저였는지는 알 수 없습니다.

<KeyIdea title="에이전트 접점을 내는 일이 새 성장 경로일 수 있습니다">
Postiz는 새 기능을 만들지 않았습니다. 이미 있던 기능에 CLI, 스킬, MCP라는 입구를 붙였을 뿐입니다. Nevo는 2026년 3월 공개된 인터뷰에서 CLI로 바꾸면 모든 과정이 훨씬 짧아진다고 말했습니다. 목표는 에이전트가 모델에 보내는 토큰을 크게 줄이는 것이라고 했습니다.
</KeyIdea>

공개 대본에서 그가 비교한 대상은 짧은 스킬 파일과 긴 요청입니다. MCP와 직접 비교하지는 않았습니다. 다만 Horizontal은 그가 스킬이 MCP보다 컨텍스트를 덜 쓴다고 말했다고 옮깁니다.

말이 아니라 숫자로도 확인해 보겠습니다. <Term id="trustmrr">TrustMRR</Term>는 Stripe API 키나 OAuth처럼 소유자가 승인한 자격 증명으로 결제 기록을 가져와 매출을 계산한다고 밝힙니다. 이 글에서 "매출"은 TrustMRR가 집계한 월 매출 합계입니다. 아래 값은 2026년 11월 11일 동기화 기준입니다.

| 월 | 매출 |
|---|---|
| 2025년 12월 | $15,785 |
| 2026년 1월 | $18,300 |
| 2026년 3월 | $82,076 |
| 2026년 6월 | $152,041 |
| 2026년 10월 | $387,146 |

1월에서 10월까지 약 21배입니다. 증가율이 가장 큰 달은 2월입니다. 1월 $18,300이던 매출이 한 달 만에 $46,019가 됐습니다. 그 사이 무엇이 바뀌었는지는 공개된 출처에 없습니다. Mixergy 인터뷰가 공개된 3월의 매출은 $82,076입니다. 10월의 $387,146은 인터뷰가 나온 뒤의 숫자입니다.

11월은 아직 집계 중($176,776)이라 비교에서 뺐습니다. 같은 동기화 기준 <Term id="mrr">MRR</Term>(월 반복 매출)은 $403,954입니다. Horizontal은 10월을 $387,214로 적었지만, 이 글은 TrustMRR 원본 값을 씁니다. Horizontal은 이 사례를 한 줄로 요약합니다.

Nevo는 인터뷰에서 사업 초기도 돌아봤습니다. 9월에 $350으로 시작해 조금씩 늘었고, 몇 달 정체하다가 약 $17K~$20K MRR에 닿았다고 합니다(연도는 공개 대본에 없습니다). 인터뷰 당시에는 월 $45,000이라고 말했습니다. TrustMRR 매출과는 기준이 달라 나란히 비교하지 않습니다.

SEObot은 사정이 다릅니다. 창업자 John Rush는 2023년 9월 SEObot을 내고 글 자동 작성을 팔아 왔습니다. Horizontal은 그의 X 팔로워 11만 6천 명이 SEObot 초기에 힘이 됐다고 씁니다. 설명을 보면, 사이트를 연결하면 SEObot이 리서치, 글 작성, CMS 게시, 내부 링크 갱신을 모두 자동으로 합니다. Horizontal은 SEObot 사이트가 200,000편 넘게 썼다고 내세운다고 전합니다(시점은 밝히지 않았습니다).

TrustMRR의 2026년 11월 11일 갱신 값으로 MRR은 $32,315, 활성 구독은 477개입니다.

Horizontal은 TrustMRR 월 매출을 인용해 SEObot 매출이 2026년 1월 $103,105에서 10월 $34,680으로 약 3분의 2 줄었다고 씁니다. 이 월별 값은 TrustMRR 원본에서 직접 읽지 못했습니다. Horizontal을 거친 2차 서술입니다.

Horizontal은 매출이 줄어든 이유가 공개되지 않았다고 씁니다. 대신 시장이 어떻게 바뀌었는지를 이렇게 적습니다.

Auto-writing and publishing articles is no longer hard, and there are many look-alike tools.

글 자동 작성과 게시가 이제 어렵지 않고 비슷한 도구가 많다는 관찰입니다. 매출이 줄어든 원인을 밝힌 말은 아닙니다.
