# 점검 체크리스트

## 범위
- [ ] git 저장소가 아니거나 소스 파일이 없으면 표를 만들지 않고 멈췄다.
- [ ] 애플리케이션 코드, 테스트, 에이전트 설정을 바꾸지 않았다.

## 표
- [ ] 손대면 안 되는 경로는 레포에서 읽은 경로만 적었고, 없으면 "없음"이다.
- [ ] 추론 가능한 조건은 열어 본 코드의 근거 경로가 있다. 지어낸 버그는 없다.
- [ ] low와 high 칸이 비어 있다. 점수, 통과 횟수, 모델 이름을 채우지 않았다.

## 변경
- [ ] 파일을 쓰기 전에 표 전문을 보여주고 승인을 받았다.
- [ ] 쓴 파일은 `docs/effort-scope-trial.md` 또는 승인한 다른 이름 하나뿐이다.
- [ ] `git status --short`를 쓰기 전과 후에 실행해, 표 밖의 변경이 없음을 확인했다.
- [ ] 검증 명령을 CLAUDE.md나 AGENTS.md에 넣지 않았다.
- [ ] 커밋, 푸시, PR을 만들지 않았다.
