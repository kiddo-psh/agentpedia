# 점검 체크리스트

## 목록
- [ ] 레포와 홈(읽기만)에서 네트워크·워크스페이스·프로세스·비밀·우회모드 관련 설정을 표로 적었다.
- [ ] `danger-full-access` 허용 여부, 쓰기 경로 범위, 비밀 exclude/브로커 단서를 빠뜨리지 않았다.
- [ ] Auto-review·에이전트 신원은 보이면 단서로만 적었고, 없다고 실패로 단정하지 않았다.
- [ ] 키·토큰 값을 출력하거나 보고서에 쓰지 않았고, `.env`/키 파일은 열지 않았다.

## 분류
- [ ] 각 행에 네트워크/워크스페이스/프로세스/비밀/우회모드(및 보조) 축과 강제·허용·지시만·미확인 중 하나를 붙였다.
- [ ] "강제"로 적은 행에 파일 경로·키 이름 또는 확인한 공식 문서가 있다. 없으면 "미확인"으로 바꿨다.
- [ ] `danger-full-access` 허용 또는 홈 전체 쓰기는 위험으로 표시했다.

## 변경
- [ ] 3단계 승인 전에는 파일을 만들거나 고치지 않았다. 부적합 환경이면 멈추고 이유를 알렸다.
- [ ] 홈 파일·네트워크 허용 목록 본문·플러그인/훅/MCP는 바꾸지 않았다.
- [ ] `git add`/`commit`/`push`/`stash`를 실행하지 않았다.
- [ ] 우회·메타데이터 접속·침해 시도를 하지 않았다.
- [ ] 레포 설정 변경은 승인한 추적 파일(또는 신규 생성)에만 적용했고 파서를 통과했다.
- [ ] `docs/persistent-agent-control-plane-audit.md`(또는 합의한 이름)에 표·권장 조치·되돌리기가 있다.
- [ ] 비밀 값 패턴 grep 결과가 비어 있다.
- [ ] `git status --porcelain` 변경이 승인 목록과 정확히 일치한다.
