# 목표: 이 레포에 "검증 루프"와 팀 공용 CLAUDE.md 습관을 들이기

보리스 체르니의 작업 방식 중 효과가 큰 세 가지를 이 레포에 맞게 적용한다.

1. **검증 수단 확보**: Claude가 스스로 결과를 확인할 수 있는 명령을 찾는다(테스트, 타입 체크, 린트, 실행).
   없으면 가장 작은 검증 명령부터 만든다. 그리고 `CLAUDE.md`에 "작업을 끝내기 전에 반드시 실행할 명령"으로 기록한다.
2. **CLAUDE.md 정비**: 빌드·테스트 명령, 코드 규칙, 과거에 자주 하던 실수를 담는다. 2~3천 토큰 안으로 짧게 유지한다.
3. **반복 작업 자동화**: 포매터가 있다면 편집 후 자동 실행되는 PostToolUse 훅을 `.claude/settings.json`에 제안한다.
   자주 쓰는 작업 1~2개는 `.claude/commands/`에 슬래시 명령으로 만든다.

## 지켜야 할 것

- 권한 확인을 전부 끄는 설정은 제안하지 않는다. 안전한 명령만 허용 목록에 넣는다.
- 훅과 명령은 만든 뒤 실제로 한 번 실행해서 동작을 확인한다.
