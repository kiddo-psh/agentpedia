# 점검 체크리스트

## 0. 중단 조건
- [ ] 코딩 에이전트 설정이나 검증 명령이 없어 맞지 않아 멈췄다면, 이 목록의 나머지 항목은 해당 없음이고 멈춘 이유만 보고했다.

## 컨텍스트 공급
- [ ] `CLAUDE.md`, `AGENTS.md`, 항상 적용되는 규칙 등 고정 컨텍스트를 모두 적었다. 조건부 규칙은 동적 컨텍스트로 분류했다.
- [ ] 동적 컨텍스트(문서 경로, 스킬, MCP)를 적었다.
- [ ] 고정 컨텍스트의 지시가 실제 레포와 맞는지 확인했다.
- [ ] 고정·동적 컨텍스트를 넘기는 시점 단서(또는 "시점 불명")를 적었다.

## 게이트·평가·트레이스
- [ ] 게이트·점검 단계(승인, 훅, CI 게이트 등) 유무와 근거 경로를 적었다. 없으면 "없음"으로 적고 만들지 않았다.
- [ ] 파일을 쓰지 않는 테스트·린트·타입 검사만 실행해 결과를 확인했고, 추측한 명령은 없다. 상태 변경 명령은 실행하지 않았다.
- [ ] 실행/미실행/동작하지 않음을 구분해 적었다.
- [ ] 과제별 평가·벤치마크 유무와 지연·토큰·비용 측정 여부를 적었다. 없으면 "없음"으로 적고 만들지 않았다.
- [ ] 트레이스로 컨텍스트 쌓임을 볼 수 있는지 예/아니오와 위치를 적었다.

## 판정과 변경
- [ ] 범용 하네스로 충분 / 게이트를 더할 시점 / 미션 크리티컬에 가깝다 중 하나로 판정하고 근거를 적었다.
- [ ] 보고서와 실패 기록 템플릿을 각각 따로 승인받았고 승인받지 않은 항목은 건너뛰었다.
- [ ] 보고서에 점검 날짜, 고정·동적 컨텍스트, 게이트, 검증 결과, 평가·비용, 트레이스, 판정, 빠진 곳과 권장 조치가 있다(만들었다면).
- [ ] `CLAUDE.md`·`AGENTS.md`에 검증 명령을 덧붙이지 않았다.
- [ ] `docs/agent-failures.md` 템플릿에 날짜, 증상, 받은 컨텍스트, 트레이스에서 본 것, 원인, 고친 곳 칸이 있다(만들었다면).
- [ ] 기존 문서를 덮어쓰지 않았다.
- [ ] 승인 전 명령 실행 전후의 `git status --short`가 같거나, 달랐다면 되돌리지 않고 보고했다.
- [ ] 작업 후 바뀐 파일이 승인한 보고서·템플릿(날짜 접미사 포함)뿐이다.
- [ ] 이번에 만든 파일에 `sk-`, `ghp_`, `-----BEGIN` 패턴이 없다.
- [ ] 기존 코드 로직, 훅, 미들웨어, 홈 디렉터리 설정은 수정하지 않았다.
- [ ] 외부 서비스 가입·도구 설치·`git commit`을 하지 않았다.
