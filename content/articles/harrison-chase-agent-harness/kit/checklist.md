# 점검 체크리스트

## 컨텍스트 공급
- [ ] 코딩 에이전트 설정과 검증 명령이 없으면 아무것도 바꾸지 않고 멈췄다(해당 시).
- [ ] `CLAUDE.md`, `AGENTS.md`, `.claude/`, `.codex/`, `.cursor/` 등 에이전트가 항상 읽는 고정 컨텍스트 파일을 모두 적었다.
- [ ] 작업 중 필요할 때 읽게 하는 동적 컨텍스트(문서 경로, 스킬, MCP)를 적었다.
- [ ] 고정 컨텍스트의 지시가 실제 레포 구조와 맞는지 확인했다.

## 검증 루프
- [ ] 실행해도 파일이 바뀌지 않는 테스트, 린트, 타입 검사 명령은 실제로 실행해 결과를 확인했고, 추측한 명령은 없다. 파일을 쓰는 빌드와 상태를 바꾸는 명령은 실행하지 않고 보고서에 "미실행"으로 적었다.
- [ ] 검증 명령이 고정 컨텍스트에 적혀 있어 에이전트가 스스로 실행할 수 있다.
- [ ] `CLAUDE.md` 또는 `AGENTS.md`에 새로 추가한 검증 명령을 다시 실행해 성공을 확인했다(추가하지 않았다면 해당 없음).
- [ ] 실행했지만 실패한 명령은 "동작하지 않음"으로, 실행하지 않은 명령은 "미실행"으로 구분해 적었다.

## 트레이스와 실패 기록
- [ ] 에이전트의 도구 호출과 실행 기록을 어디서 볼 수 있는지 적었다.
- [ ] 실패 사례를 남길 위치(`docs/agent-failures.md`)가 있거나, 없는 이유를 적었다.

## 변경
- [ ] 사용자가 승인한 파일만 바꿨다.
- [ ] 보고서는 승인한 경우에만 만들었고, 기존 문서를 덮어쓰지 않았다.
- [ ] `git status`의 변경 파일이 승인한 목록(`docs/agent-harness-audit.md` 등)과 정확히 같다.
- [ ] 이번에 만들거나 수정한 모든 파일에 `sk-`, `ghp_`, `-----BEGIN` 패턴이 없다.
- [ ] 승인 전에는 파일을 하나도 바꾸지 않았다.
- [ ] 기존 코드 로직, 훅, 미들웨어, 홈 디렉터리 설정은 수정하지 않았다.
- [ ] 외부 서비스 가입이나 도구 설치를 하지 않았다.
