# 점검 체크리스트

## 목록
- [ ] 레포의 지침·규칙·MCP/도구 설명 후보를 경로와 함께 표로 적었다.
- [ ] 각 항목을 매 턴 필수 / 필요할 때만 / 접두를 흔듦 중 하나로 분류했고 근거를 적었다.
- [ ] 사용 빈도를 재지 못한 항목은 "추정·미측정"으로 표시했다.
- [ ] 키·토큰 값을 출력하지 않았다.

## 보고서와 변경
- [ ] 승인 전에는 파일을 만들거나 고치지 않았다. 부적합이면 멈추고 이유를 알렸다.
- [ ] `docs/token-context-budget-audit.md`(또는 합의한 이름)에 분류 표·접두 후보·측정 방법·되돌리기가 있다.
- [ ] 홈 전역 설정·모델·요금제·프로바이더 플래그를 바꾸지 않았다.
- [ ] 유료 API 대량 호출·프로덕션 재현 벤치를 돌리지 않았다.
- [ ] 컨텍스트 줄 삭제 전용 감사나 CLAUDE.md 검증 명령 추가를 하지 않았다.
- [ ] 레포 변경은 승인한 git 추적 파일에만 적용했고, JSON 등은 파서를 통과했다.
- [ ] `git status --porcelain` 변경이 승인 목록과 일치한다.
- [ ] `git add`/`commit`/`push`/`stash`를 실행하지 않았다.
