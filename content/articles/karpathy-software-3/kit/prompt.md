# 목표: 내 프로젝트를 "에이전트가 읽고 쓸 수 있는" 형태로 만들기

카파시의 Software 3.0 관점을 이 레포에 적용한다. 범위는 아래 두 가지다.

1. **문서 점검**: README, docs, 기여 가이드에서 사람만 실행할 수 있는 지시를 찾는다.
   예: "설정 화면에서 클릭", "대시보드에서 확인". 이런 지시를 셸 명령, 스크립트, API 호출로 바꾼 수정안을 만든다.
2. **에이전트 진입점**: 레포 루트에 에이전트용 요약 문서(`AGENTS.md` 또는 `CLAUDE.md`)가 없다면 초안을 만든다.
   빌드, 테스트, 실행 명령과 주요 디렉터리 설명을 담는다. 이미 있으면 빠진 명령만 보강한다.

## 지켜야 할 것

- 실제로 레포에 존재하는 명령만 적는다. 추측한 명령은 적지 않는다.
- 각 명령은 직접 실행해서 동작을 확인한 뒤 문서에 넣는다.
- 변경은 작게 나누어 제안하고, 사용자가 diff를 확인하게 한다.
