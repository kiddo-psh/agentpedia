# 적용 후 점검

- [ ] README, `docs/`, `CONTRIBUTING.md`에서 "클릭"류 지시를 모두 찾았고, 각각 명령으로 바뀌었거나 바꿀 수 없는 이유가 적혀 있다.
- [ ] 문서에 새로 넣은 명령은 모두 실제로 실행해 봤고 성공했다.
- [ ] 레포 루트의 `AGENTS.md` 또는 `CLAUDE.md`에 빌드·테스트·실행 명령이 있다.
- [ ] 같은 진입 문서에 "작게 나누고, 단계마다 검증 명령을 실행한다"는 작업 규칙이 있다.
- [ ] `git status`와 `git diff --stat`에 문서 파일(README, `docs/`, `CONTRIBUTING.md`, `AGENTS.md` 또는 `CLAUDE.md`)만 나온다.
- [ ] 새 에이전트 세션에서 진입 문서만 읽고, 클릭 없이 테스트를 돌릴 수 있다.
- [ ] 외부 서비스, 원격 저장소, 배포 환경을 바꾸는 명령을 실행하지 않았고, 계정을 만들지 않았다. 그런 단계는 문서에 이유만 적혀 있다.
