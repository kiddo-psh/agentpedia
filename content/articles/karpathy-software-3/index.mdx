## 한 줄 요약

카파시는 지금을 **세 번째 소프트웨어 시대**로 봅니다. 이제 영어로 쓴 프롬프트도 프로그램입니다.

<KeyIdea title="세 가지 소프트웨어">
- **Software 1.0**: 사람이 직접 작성하는 코드
- **Software 2.0**: 데이터로 학습한 신경망의 가중치
- **Software 3.0**: LLM을 움직이는 자연어 프롬프트

세 방식은 서로를 대체하지 않고 공존합니다. 어떤 문제를 어느 층으로 풀지 고르는 것이 개발자의 새 역량입니다.
</KeyIdea>

## LLM은 새로운 운영체제

카파시는 LLM을 전기처럼 쓰는 **유틸리티**, 막대한 투자가 드는 **팹(fab)**, 그리고 컨텍스트 창을 메모리처럼 관리하는 **운영체제**에 비유합니다. 지금은 1960년대 메인프레임 시절처럼 중앙 컴퓨팅을 시분할로 빌려 쓰는 단계라는 것이죠.

## 부분 자율: 오토노미 슬라이더

완전 자율 에이전트를 바로 만들기보다, 사람이 **생성 → 검증** 루프를 빠르게 돌릴 수 있는 제품이 지금 현실적인 선택이라고 말합니다. 좋은 예로 Cursor나 Perplexity처럼 자율성의 정도를 사용자가 조절할 수 있는 도구를 듭니다.

<Steps>
1. AI가 한 번에 만드는 변경의 크기를 작게 유지한다.
2. 결과를 사람이 빠르게 검증할 수 있는 UI나 diff를 제공한다.
3. 신뢰가 쌓이면 슬라이더를 조금씩 올린다.
</Steps>

## 에이전트를 위한 설계

문서는 이제 사람과 LLM이 **함께** 읽습니다. "여기를 클릭하세요" 같은 지시는 에이전트가 실행할 수 없으니, 명령어나 API 호출로 바꿔 써야 합니다. 마크다운 문서나 `llms.txt`처럼 LLM이 읽기 좋은 형태를 함께 제공하라는 제안도 있습니다.
