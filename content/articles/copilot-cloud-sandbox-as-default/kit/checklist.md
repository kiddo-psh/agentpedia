# 점검 체크리스트

## 분류
- [ ] 로컬 전용 / 클라우드 기본 / Actions 환경 후보를 표로 적고 근거 경로를 붙였다.
- [ ] 근거 없는 항목은 미확인으로 표시하고 추측으로 채우지 않았다.
- [ ] MCP 상세 인벤토리·침해 흔적 점검으로 범위를 넓히지 않았다.

## 정책
- [ ] Copilot in the cloud, SSO, MCP 허용 목록, 도구 승인, 레포 제외, 과금 인지 여부를 적었다.
- [ ] 확인하지 못한 항목은 미확인과 확인할 위치만 적었다.
- [ ] 조직 정책 UI·managed-settings를 직접 수정하지 않았다.
