# 점검 체크리스트

## 경로
- [ ] CI 설정 파일의 위치와 실행 단계를 적었다.
- [ ] 테스트·린트·타입 검사 명령을 실제 설정 파일에서 읽어 적었다.
- [ ] 테스트 파일 개수와 종류를 적었다.
- [ ] 개발 서버 명령을 설정 파일에서 읽어 적었고, 실행하지 않았다(또는 해당 없음이라고 적었다).

## 실행
- [ ] 실행 전에 명령 목록과 부작용 여부를 보여 주고 승인받았으며, 승인받은 명령만 실행했다.
- [ ] 파일을 바꾸지 않는 명령만 실행했다.
- [ ] 각 명령의 걸린 시간과 성공 여부를 적었다.
- [ ] 시작과 끝의 `git status --short --ignored`를 비교했고, 이미 존재하던 무시 디렉터리 안의 변경은 이 비교로 잡히지 않는다는 점을 보고서에 적었다.
- [ ] 검증 명령이 없거나 git 레포가 아니면 아무것도 바꾸지 않고 멈췄다(해당 없음 가능).
- [ ] API 키·토큰 값을 출력하지 않았고 홈 디렉터리 전역 설정을 바꾸지 않았다.

## 변경
- [ ] 테스트, CI 설정, 빌드 스크립트를 삭제하거나 수정하지 않았다.
- [ ] 삭제 후보는 보고서에 근거와 함께 적기만 했고 사용자 판단에 맡겼다.
- [ ] 보고서와 `CLAUDE.md`·`AGENTS.md` 변경은 사용자가 승인한 것만 했다.
- [ ] `git commit` 등 git 기록을 바꾸는 명령을 쓰지 않았다.

## 보고서
- [ ] 보고서가 이미 있으면 덮어쓰지 않고 날짜 붙은 새 파일로 썼다(해당 없음 가능).
- [ ] 보고서에 개발 서버는 실행하지 않아 속도를 재지 못했다고 적었다(또는 해당 없음).
- [ ] 보고서에 점검 날짜, 명령별 시간·결과 표, CI 구성, 테스트 파일 수와 종류가 들어 있다.
- [ ] 보고서에 빠진 곳과 느릴 수 있는 곳, 권장 조치가 들어 있다.
- [ ] 보고서의 테스트 후보에는 근거만 있고 삭제 권고가 없다(후보가 없으면 해당 없음).
- [ ] 보고서·`CLAUDE.md`·`AGENTS.md` 변경 전에 계획을 보여 주고 두 번째 승인을 받았다.
- [ ] `CLAUDE.md`·`AGENTS.md`에는 기존 내용을 지우지 않고 한 줄만 덧붙였다(덧붙이지 않았다면 해당 없음).
- [ ] `CLAUDE.md`·`AGENTS.md`에 덧붙인 명령은 이번 실행에서 실제로 돌려 성공한 것이다(덧붙이지 않았다면 해당 없음).
- [ ] 덧붙인 파일은 현재 Claude Code 버전이 실제로 읽는 파일이다(CLAUDE.md가 있으면 CLAUDE.md, AGENTS.md만 있으면 2.1.281 이상, Project instructions 설정이 `claude-md-or-agents-md` 또는 `claude-md-and-agents-md`, 상위 디렉터리의 `CLAUDE.md`·`.claude/CLAUDE.md`·`CLAUDE.local.md` 부재, 내장 플러그인 상태 확인).
- [ ] 보고서에 대상 파일 판정 근거(Claude Code 버전, Project instructions 값, CLAUDE.md 유무)나 건너뛴 이유를 적었다.
- [ ] 실행으로 새로 생긴 캐시·산출물을 되돌리지 않고 보고서에 적었다(없으면 해당 없음).
