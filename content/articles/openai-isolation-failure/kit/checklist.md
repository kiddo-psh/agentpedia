# 점검 체크리스트

## 목록
- [ ] 레포 안 에이전트 설정(`.claude/`, `.mcp.json`, `.codex/`)의 네트워크, 비밀 파일, 위험 명령 제한을 모두 적었다.
- [ ] 홈 디렉터리의 Claude Code·Codex 설정에서 같은 항목을 읽기만 하며 적었다.
- [ ] 패키지 설치처럼 허용된 구멍을 목록에 적었다.
- [ ] 보고서 표에 네트워크, 비밀 파일, 위험 명령, 샌드박스 네 항목이 모두 있고, 각 행에 위치와 유형이 적혀 있다.

## 지시와 강제
- [ ] 각 제한에 강제, 지시, 구멍, 미확인 중 하나를 붙였다.
- [ ] 비밀 파일이나 위험 명령이 지시로만 막혀 있는 항목을 위험으로 표시했다.
- [ ] 확인하지 못한 도구 동작은 추측하지 않고 "미확인"으로 적었다.

## 변경
- [ ] 3단계에서 사용자가 승인한 뒤에만 파일을 만들거나 고쳤다. 승인 전에는 읽기만 했다.
- [ ] 맞지 않는 환경이면 파일을 하나도 바꾸지 않고 이유를 알린 뒤 멈췄다.
- [ ] 홈 디렉터리 파일은 수정하지 않았다.
- [ ] 외부 접속이나 우회를 시도하지 않았다.
- [ ] 도구, 플러그인, 확장 프로그램을 설치하거나 삭제하지 않았고, 네트워크 허용 목록은 바꾸지 않았다.
- [ ] 레포 설정은 사용자가 승인한 항목만 바꿨고, 바꾼 파일이 파서를 통과했다.
- [ ] 키·토큰의 값을 어디에도 출력하거나 저장하지 않았다.
- [ ] `docs/agent-isolation-audit.md`와 수정한 설정 파일에 비밀 값 패턴이 없음을 `grep -nEi -e '(^|[^a-z])sk-[a-z0-9]{16,}|ghp_[A-Za-z0-9]{20,}|github_pat_|xox[bp]-|AKIA[0-9A-Z]{12,}|Bearer +[A-Za-z0-9._-]{16,}|-----BEGIN' <파일들>`로 확인했다(결과 없음). `grep`이 없으면 `Select-String -Pattern '<같은 패턴>' -Path <파일들>`을 썼다.
- [ ] `docs/agent-isolation-audit.md`가 존재하고, 항목별 현재 차단 여부, 허용된 구멍, 권장 조치, 설정을 되돌리는 방법이 들어 있다.
- [ ] `git status --porcelain`에 나온 변경과 새 파일이 승인 목록과 정확히 일치한다. 승인하지 않은 파일이 하나라도 있으면 실패다.
