# 점검 체크리스트

## 현황
- [ ] 세 설정에 `permissions`·`autoMode`가 없으면 보고서를 만들지 않고 멈췄다(해당 없음). 설정 파일이 없고 사용자가 원하면 짧은 기본 규칙 보고서만 만들고 settings 교체는 건너뛰었다.
- [ ] 세 파일의 allow·ask·deny·defaultMode·autoMode·disableAutoMode를 읽었다.
- [ ] 버전과 `claude auto-mode defaults` 동작 여부를 적었다(못 하면 그 사실을 적었다).
- [ ] 문서상 무시되는 항목은 "무시됨" + 사용자 할 일로만 적었고, 설정 장문을 베끼지 않았다.
- [ ] `disableAutoMode`가 있으면 보고서 맨 위에 적었다.

## 분류 (기사 claim)
- [ ] 허용 규칙마다 넓음·좁음·판단 필요 중 하나를 붙였다.
- [ ] ask·deny를 사람 확인 지점으로 적었다.
- [ ] 레포 작업을 **분류기에 맡길 일 / 기본 차단 / 사람이 직접 볼 일** 세 줄로 나눴다.
- [ ] 사람이 볼 일에 승인 피로·분류기 한계(모호한 의도)를 이유로 적었다.
- [ ] 기본 차단 작업이 필요한지 사용자에게 물었다.

## 변경
- [ ] 표와 교체 계획을 보여주고 승인받은 뒤에만 파일을 만들거나 고쳤다.
- [ ] 보고서에 날짜, 버전, 규칙 표, 세 줄 분류, 권장 조치, 홈 할 일이 있다. 설정 백과사전 문단은 없다.
- [ ] 권한 모드를 바꾸지 않았고 auto를 켜지 않았다.
- [ ] 홈·`settings.local.json`은 수정하지 않았다.
- [ ] 승인한 경우에만 레포 `.claude/settings.json`의 넓은 규칙을 좁혔고, JSON이 통과했다.
- [ ] 교체 후 permissions를 다시 읽어 승인 목록과 비교했고, 다른 키는 그대로다.
- [ ] 보고서에 키·토큰 값이 없다.
- [ ] 기존 보고서를 덮어쓰지 않았다.
- [ ] 코드 수정·푸시·배포·삭제·설치를 하지 않았다.
