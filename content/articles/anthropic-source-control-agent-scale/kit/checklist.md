# 점검 체크리스트

## 맞는지 판단
- [ ] 레포에 CI 설정이 있는지 확인했고, 없으면 멈췄다.

## 정리
- [ ] CI 한 번이 하는 일(체크아웃, 설치, 빌드, 테스트)을 설정 파일에서 읽어 적었다.
- [ ] 머지 규칙과 리뷰 규칙을 적었다. 파일에서 읽을 수 없는 설정은 '확인 불가'로 적었다.
- [ ] 주당 변경 수를 프롬프트의 명령으로 확인했고, 이력이 잘렸으면 '측정 불가'로 적었다.

## 병목 후보
- [ ] 변경이 열 배가 된다는 가정에서 먼저 막힐 병목 후보를 하나 이상 근거와 함께 꼽았다.
- [ ] 후보마다 확인한 근거와 추측을 구분했다.
- [ ] 저장소를 다른 시스템으로 옮기라는 권고가 없다.

## 승인과 변경
- [ ] 3단계 계획을 보여주고 사용자의 승인을 받은 뒤에 파일을 만들었다.
- [ ] `git status --porcelain` 결과에 `docs/agent-scale-bottlenecks.md`(와 새로 만든 `docs/`)만 새 파일로 나온다.
- [ ] 보고서에 점검 날짜, 측정 절(또는 '측정하지 않음'), 다음에 확인할 일이 있다.
- [ ] 승인을 받지 못했다면 파일을 만들지 않고 1~2단계 요약만 냈다.
- [ ] 보고서에 적은 수치와 명령을 다시 실행하거나 읽어 일치함을 확인했다.
- [ ] 프롬프트 5단계의 `grep -nE` 비밀 값 패턴 명령이 아무것도 출력하지 않았다.
