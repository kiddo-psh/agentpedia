# 점검 체크리스트

## 목록
- [ ] 레포 안 에이전트 설정(`.mcp.json`, `.claude/`, `.codex/`, `.cursor/`)의 MCP 서버·훅·플러그인을 모두 적었다.
- [ ] 홈 디렉터리의 Claude Code·Codex 설정에서 플러그인·마켓플레이스·MCP 서버·훅을 모두 적었다.
- [ ] 에디터 확장 목록과 버전을 실제 명령으로 확인했다.
- [ ] 각 항목에 출처와 위험도를 붙였다.

## 알려진 침해 흔적
- [ ] Claude Code 확장 2.1.312·2.1.313 버전이 없는지 확인했다.
- [ ] `authorized_keys`에 `svc-telemetry` 키가 없는지 확인했다.
- [ ] `com.apple.sysmond.plist`, `~/.config/.smt`, `~/.config/.smtk`, `/tmp/.stk_*`이 없는지 확인했다(해당 OS만).
- [ ] 다른 앱이 설치한 플러그인·훅(예: Postman 플러그인)이 있는지 확인했다.

## 키
- [ ] 키·토큰의 위치와 이름만 적었고, 값은 어디에도 출력하거나 저장하지 않았다.
- [ ] 외부 서비스에 맡긴 키가 있는지 사용자에게 확인했다.

## 변경
- [ ] 홈 디렉터리 파일은 수정하지 않았다.
- [ ] 레포 설정은 사용자가 승인한 항목만 바꿨고, 바꾼 파일이 파서를 통과했다.
- [ ] `docs/agent-trust-audit.md`에 비밀 값 패턴(`sk-`, `ghp_`, `-----BEGIN`)이 없음을 grep으로 확인했다.
