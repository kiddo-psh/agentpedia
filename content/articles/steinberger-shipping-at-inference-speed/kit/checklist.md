# 적용 후 점검

- [ ] 핵심 기능 하나를 CLI 명령 한 줄로 실행할 수 있다.
- [ ] CLI가 UI와 같은 기존 함수를 호출한다 (로직 복사나 재구현 없음).
- [ ] CLI를 실제로 실행했고, 출력이 기대한 결과와 맞았다.
- [ ] README 또는 AGENTS.md/CLAUDE.md에 실행 명령과 실제 출력 예시가 있다.
- [ ] 같은 문서에 '이 기능을 바꾼 뒤 이 명령으로 결과를 확인한다'는 안내가 있다.
- [ ] 문서에 적힌 실행 명령을 레포 루트의 새 셸에서 그대로 붙여 넣어 실행하면, 문서의 출력 예시와 같은 형태의 출력이 나온다.
- [ ] UI나 기존 화면 코드는 바뀌지 않았다.
- [ ] 새 의존성을 추가했다면, 계획에서 밝히고 승인받은 것뿐이다.
- [ ] 기존 테스트·타입 체크·린트가 있다면 모두 통과한다.
