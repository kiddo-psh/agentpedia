# 점검 체크리스트

## 맞음
- [ ] Claude Code로 여러 파일을 찾아 요약할 일이 없으면 보고서를 만들지 않고 멈췄다.
- [ ] MCP 서버 이름은 적되 비밀 값은 적지 않았다.

## 빈 표
- [ ] `docs/code-mode-on-off.md`의 턴·토큰·시간 칸이 비어 있다.
- [ ] MCP 도구가 스크립트에 남았는지를 적는 칸이 있고, 그 칸도 비어 있다.
- [ ] 표는 공식 문서가 MCP 도구 이름으로 규칙을 탄다고 한 점과, 그 호출이 샌드박스 밖에 있다는 점을 한 줄씩만 적는다.

## 하지 않은 일
- [ ] `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE`와 설정 파일을 바꾸지 않았다.
- [ ] REPL 훅과 권한 규칙을 추가하지 않았다.
- [ ] 검증 명령을 CLAUDE.md에 덧붙이지 않았다.
- [ ] 애플리케이션 코드를 수정하지 않았다.
- [ ] 승인 전에 파일을 만들지 않았고, 기존 파일을 덮어쓰지 않았다.
