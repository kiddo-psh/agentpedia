# 목표: Code Mode를 켜고 끈 비교표를 비워 두기

2026년 11월 Code Mode 공지 뒤 한 인용 글은 MCP가 끝났다고 적었다. 공식 문서는 스크립트 안의 호출이 MCP 도구 이름으로 권한 규칙을 탄다고 적는다. 이 키트는 같은 검색 요약을 켜고 끄고 재는 표만 만들고, 턴·토큰·시간은 비운다. 측정값을 채우거나 환경 변수를 바꾸는 일은 하지 않는다. REPL 훅은 Code Mode 경계 키트의 범위다.

## 절대 지킬 것

- 승인받기 전에는 파일을 만들거나 고치지 않는다.
- `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE`를 켜거나 끄지 않는다. `~/.claude/settings.json`과 프로젝트 설정을 수정하지 않는다.
- REPL 훅, deny·ask 규칙, auto 모드를 추가하거나 바꾸지 않는다.
- 턴, 토큰, 시간, 비율을 추정해 적지 않는다. 재지 않았으면 칸은 빈칸이다.
- 검증 명령을 CLAUDE.md·AGENTS.md에 덧붙이지 않는다. 그건 Boris Cherny 키트 범위다.
- 애플리케이션 코드, 커밋, 푸시, 설치, 배포를 하지 않는다. 키와 토큰 값은 출력하지 않는다.

## 0. 맞는지 먼저 판단하기

레포를 읽는다. 마크다운이 여러 개 있거나, `.mcp.json`·`.claude` 안에 MCP 서버 이름이 있으면 비교할 과제가 있다. Claude Code를 쓰지 않고 검색할 파일도 없으면 이유를 설명한 뒤 여기서 멈춘다.

## 1. 읽기만 하기

마크다운 개수, MCP 서버 이름(값과 비밀은 제외), Code Mode 환경 변수가 보이는지만 적는다. 변수가 없어도 켜지 않는다. 공식 문서(https://code.claude.com/docs/en/code-mode)와 한 줄로만 대조한다. MCP 도구 호출이 스크립트 안에서 도구 이름으로 규칙을 탄다는 문장과, JavaScript·파일·웹·MCP 호출이 샌드박스 밖에서 돈다는 문장만 적는다.

## 2. 빈 표 계획을 보여주고 승인받기

`docs/code-mode-on-off.md`에 넣을 내용을 먼저 보여 준다. 과제 문장은 "여러 파일을 찾아 요약"처럼 이 레포에 맞게 한 줄. 켜기/끄기 칸의 턴·토큰·시간·MCP 도구가 스크립트에 남았는지는 빈칸이다. 승인 전에는 파일을 만들지 않는다. 같은 이름의 파일이 있으면 덮어쓰지 말고 다른 이름을 제안한 뒤 고를 때까지 멈춘다.

## 3. 승인 뒤에만 파일을 만들기

승인한 경우에만 `docs/code-mode-on-off.md`를 만든다. 실행 방법은 환경 변수를 셸에서 직접 켜고 끄는 한 줄과 문서 URL뿐이다. 숫자를 채우지 않는다. 만든 뒤 `rg -n . docs/code-mode-on-off.md`를 실행해서 턴·토큰·시간 칸에 숫자가 없는지 확인한다.
