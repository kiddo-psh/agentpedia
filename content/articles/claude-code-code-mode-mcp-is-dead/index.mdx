2026년 11월 18일, X 계정 melvynx가 전날 ClaudeDevs 공지를 인용했습니다. 본문은 한 줄입니다.

<Quote source="melvyn-mcp-dead">
Finnaly MCP is dead
</Quote>

맞춤법이 틀린 그 줄은 MCP가 끝났다는 선언입니다. 공지 자체는 그보다 짧고, 실험이라고 말합니다.

<Quote source="claude-devs-code-mode">
Check out Code Mode, a new, experimental way for Claude Code to work with tools. Claude writes scripts that chain your tools together in sophisticated ways, and it can answer you while long commands are still running.
</Quote>

Claude가 도구를 잇는 스크립트를 쓰고, 긴 명령이 도는 동안에도 답을 할 수 있다는 공지입니다. 옵트인은 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`입니다. 공지 시각은 2026년 11월 17일 21:18 UTC이고, 인용 글은 다음 날 07:56 UTC입니다.

## 공지는 도구를 스크립트로 잇는 일이다

질문은 그 스크립트가 도구를 없애느냐입니다. 공식 문서의 답은 호출 방식이 바뀐다는 쪽입니다. Code Mode가 꺼져 있으면 Claude는 Bash, Read, Edit 같은 도구를 직접 요청하고, 결과를 읽은 뒤 다음을 고릅니다. 켜져 있으면 Claude가 JavaScript를 쓰고, Claude Code가 그 코드를 세션에서 실행합니다. 코드 한 덩어리가 명령을 병렬로 돌리고, 한 결과를 다음 호출에 넣고, Claude가 읽을 부분만 돌려줄 수 있습니다.

<KeyIdea title="도구는 남고 호출이 코드 안으로 들어갑니다">
Code Mode는 실험 기능이고 기본은 꺼져 있습니다. 릴리스마다 바뀌거나 빠질 수 있다고 문서가 적습니다. 버전 하한은 Claude Code v2.1.323입니다. 더 오래된 버전은 환경 변수가 있어도 Code Mode 없이 시작합니다.
</KeyIdea>

대화 화면에는 편집 diff 같은 도구 호출이 보이고, 코드는 `Ctrl+O`로 여는 트랜스크립트에 접혀 있습니다. 문서가 권하는 자리는 여러 파일에 같은 변경이 반복되거나, 검색 결과를 거른 뒤 읽거나, 서로 독립인 명령을 동시에 돌릴 때입니다.

## 문서는 MCP 도구 이름을 그대로 둔다

그래서 "MCP가 끝났다"는 반응과 문서를 나란히 놓으면 결이 다릅니다. 문서의 권한 절은 스크립트 안의 각 호출이 평소 도구 이름으로 `deny`·`ask` 규칙과 PreToolUse 훅을 탄다고 적습니다. 그 이름에는 Bash와 <Term id="mcp">MCP</Term> 도구가 함께 있습니다.

<Quote source="cc-docs-code-mode">
Each tool call in the code goes through your deny and ask permission rules and PreToolUse hooks under the tool's usual name, such as Bash or an MCP tool's name.
</Quote>

스크립트 안의 호출도 Bash이거나 MCP 도구 이름인 채로 규칙과 훅을 탑니다. MCP 서버를 치우라는 문장은 이 페이지에 없습니다. <Term id="cc-code-mode">Code Mode</Term>는 그 도구를 하나씩 대화로 왕복하지 않고, JavaScript가 이어서 부르게 하는 쪽에 가깝습니다.

## 그 호출은 샌드박스 밖에 있다

권한 규칙이 남았다고 호출이 샌드박스 안으로 들어가는 것은 아닙니다. 문서가 이어서 적습니다.

<Quote source="cc-docs-code-mode">
The JavaScript itself and its file, web, and MCP tool calls run outside the sandbox.
</Quote>

JavaScript와 파일·웹·MCP 도구 호출은 샌드박스 밖에서 돕니다. 샌드박스 설정이 적용되는 것은 코드가 돌리는 셸 명령입니다. 문서가 그 호출까지 격리하려면 Claude Code 자체를 컨테이너나 가상 머신에서 돌리라고 적습니다. 이 페이지는 MCP가 사라졌다고 말하지 않고, MCP 호출이 샌드박스 밖에 남는다고 말합니다.

## 같은 검색을 켜고 끄고 재는 일이다

줄어드는지 늘어나는지는 이 글이 재지 않았습니다. 문서가 예로 드는 자리는 검색 결과를 거른 뒤 읽는 일입니다. 여러 파일을 찾아 요약하는 같은 과제를, Code Mode를 끈 세션과 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`로 켠 세션에서 각각 시키고, 턴과 토큰과 시간을 본인 화면에서 적으면 됩니다. 이 글의 표는 그 칸이 비어 있습니다. 프로젝트 설정의 `env`는 이 변수를 무시하므로, 저장소가 대신 켜 주지는 않습니다.

가져갈 구분은 반응과 문서입니다. 인용 글의 한 줄은 MCP가 끝났다는 말이고, 문서는 MCP 도구를 스크립트 안에서 부릅니다. 왕복이 줄었는지는 같은 검색을 두 번 돌려 봐야 합니다.
